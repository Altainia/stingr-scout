# Plan 3 — Hub UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the hub's web screens: dashboard, event setup (events, Red side, schedule, teams), the match and pit form editors with a live tablet preview, the coverage grid, team rankings and team pages, the webcam QR scanner, export/backup/restore, and settings.

**Architecture:** A Svelte 5 single-page app in a new `hub/ui` workspace, built by Vite with base `/hub/` into `hub/ui/dist`, which the hub server (Plan 1) already serves at `/hub/`. Hash routing (`#/coverage`, `#/teams/5098`, …). Every page receives one `api` object (a typed client for the hub's existing JSON API) as a prop, so pages are tested with a fake API. Pure logic (form editing operations, routing, sorting, formatting, QR de-duplication) lives in plain TypeScript modules. The form preview reuses the tablet's own `QuestionCard` component, and the hub UI shares the tablet's stylesheet plus a small hub stylesheet.

**Tech Stack:** Svelte 5.57.2, Vite 8.3.4, jsQR 1.4.0; tests: Vitest 5.0.5 (jsdom, @testing-library/svelte 5.4.2), Playwright 1.64.1.

**Spec:** `docs/superpowers/specs/2026-10-15-stingr-scout-design.md` (§6 is the hub; §6.3 event setup incl. `redSide`; §6.4 forms editor; §6.5 coverage; §6.6 team summaries; §6.7 export and backup; §5.5 QR).

**Builds on:** Plan 1 (hub API) and Plan 2 (tablet app, `QuestionCard`, `ConfirmDialog`, `app.css`). No hub server changes are needed except where a task says so.

## Global Constraints

- Served at `http://localhost:5098/hub/` on the hub laptop (a modern desktop browser). Vite `base: '/hub/'`; output `hub/ui/dist` (the path `main.ts` already serves).
- Routing is hash-based only (the server has no SPA fallback under `/hub/`).
- All API calls are same-origin relative paths (`/api/...`) made through `createApi()`; pages never call `fetch` directly. Downloads (CSV export, backup) are plain links to `/api/export/*` and `/api/backup`.
- `svelte-check` is not used (TypeScript 7); `tsc` with `"types": ["node", "svelte"]` checks `.ts` and `.svelte.ts` files.
- Form controls have an `aria-label` matching their visible label; page headings are `<h1>`.
- The hub never changes a published form version; editing always works on the draft and publishing creates the next version (spec §4.1).
- Question keys and option values that appear in any published version are locked in the editor (changing them would split the data).
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Commit only after `npm test` and `npm run typecheck` pass.

## Review Focus

1. A mentor edits a form and leaves the page within the 0.6 s autosave delay → the pending change is still saved (Task 10, `formsEditor.test.ts` "saves pending changes when leaving the page").
2. A question whose key is already in published data is renamed → its key must not change (Task 8, `formEdit.test.ts` "keeps a published key when the label changes").
3. A schedule CSV with mistakes → nothing is imported and every bad line is listed so it can be fixed (Task 7, `event.test.ts` "lists every problem in a bad CSV").
4. Coverage and team pages opened before any event or form exists → a clear "choose an event" message with a link, not a blank page (Task 5, `pages.test.ts` "explains when no event is selected").
5. The webcam keeps seeing the same QR code for several seconds → it is sent to the hub once, not 30 times a second (Task 14, `qr.test.ts` "ignores the same code seen again within 3 seconds").

```ts
import type { EventInfo, FormDef, FormKind, ScheduleMatch, ScoutRecord, Side } from '@stingr/shared';
import type { AdbStatus } from '../../../server/src/adb';
import type { CoverageRow } from '../../../server/src/coverage';
import type { DeviceRow } from '../../../server/src/store/devices';
import type { PublishResult } from '../../../server/src/store/forms';
import type { TeamSummary } from '../../../server/src/summaries';

export type { AdbStatus, CoverageRow, DeviceRow, PublishResult, TeamSummary };

export class ApiError extends Error {
  readonly status: number;
  constructor(status: number, message: string) {
    super(message);
    this.status = status;
  }
}

export interface EventsView { events: EventInfo[]; current: EventInfo | null }
export interface FormValidation { errors: string[]; warnings: string[] }
export interface DevicesView { adb: AdbStatus; devices: DeviceRow[] }
export interface TeamDetail {
  summary: TeamSummary;
  matchForm: FormDef | null;
  pitForm: FormDef | null;
  matchRecords: ScoutRecord[];
  pitRecords: ScoutRecord[];
}
export type QrResult =
  | { status: 'partial'; group: string; have: number; total: number }
  | { status: 'stored' | 'duplicate'; record: { id: string; revision: number; kind: FormKind; team: number; matchKey?: string; slot?: string; scout: string } }
  | { status: 'invalid'; reason: string };

type Http = (input: string, init?: RequestInit) => Promise<Response>;

export function createApi(http: Http = (input, init) => fetch(input, init)) {
  async function call<T>(method: string, path: string, body?: unknown, opts: { type?: string; accept?: number[] } = {}): Promise<T> {
    const init: RequestInit = { method };
    if (body !== undefined) {
      const type = opts.type ?? 'application/json';
      init.headers = { 'content-type': type };
      init.body = type === 'application/json' ? JSON.stringify(body) : (body as BodyInit);
    }
    let res: Response;
    try {
      res = await http(path, init);
    } catch {
      throw new ApiError(0, "Can't reach the hub server. Is it still running?");
    }
    if (res.ok || opts.accept?.includes(res.status)) return (await res.json()) as T;
    let message = `The hub answered HTTP ${res.status}`;
    try {
      const b = (await res.json()) as { error?: unknown; errors?: unknown };
      if (typeof b.error === 'string') message = b.error;
      else if (Array.isArray(b.errors)) message = b.errors.join('\n');
    } catch {
      // not JSON
    }
    throw new ApiError(res.status, message);
  }

  return {
    events: () => call<EventsView>('GET', '/api/events'),
    createEvent: (ev: { key: string; name?: string; redSide?: Side }) => call<EventsView>('POST', '/api/events', ev),
    setCurrentEvent: (key: string) => call<EventsView>('PUT', '/api/events/current', { key }),
    schedule: () => call<ScheduleMatch[]>('GET', '/api/schedule'),
    saveSchedule: (matches: ScheduleMatch[]) => call<ScheduleMatch[]>('PUT', '/api/schedule', matches),
    importScheduleCsv: (csv: string) =>
      call<{ matches: number } | { errors: string[] }>('POST', '/api/schedule/csv', csv, { type: 'text/csv', accept: [422] }),
    fetchTba: () => call<{ matches: number; teams: number; scheduleReplaced: boolean }>('POST', '/api/schedule/tba'),
    teams: () => call<number[]>('GET', '/api/teams'),
    addTeam: (team: number) => call<number[]>('POST', '/api/teams', { team }),
```

```ts
import type { FormKind } from '@stingr/shared';

export type Route =
  | { page: 'dashboard' }
  | { page: 'event' }
  | { page: 'forms'; kind: FormKind }
  | { page: 'coverage' }
  | { page: 'teams' }
  | { page: 'team'; team: number }
  | { page: 'qr' }
  | { page: 'data' }
  | { page: 'settings' }
  | { page: 'notfound' };

export function parseRoute(hash: string): Route {
  const [first, second, ...rest] = hash.replace(/^#\/?/, '').split('/').filter(Boolean);
  if (rest.length) return { page: 'notfound' };
  switch (first ?? '') {
    case '': return { page: 'dashboard' };
    case 'event': return second ? { page: 'notfound' } : { page: 'event' };
    case 'forms':
      if (second === undefined || second === 'match') return { page: 'forms', kind: 'match' };
      return second === 'pit' ? { page: 'forms', kind: 'pit' } : { page: 'notfound' };
    case 'coverage': return { page: 'coverage' };
    case 'teams':
      if (second === undefined) return { page: 'teams' };
      return /^\d{1,5}$/.test(second) ? { page: 'team', team: Number(second) } : { page: 'notfound' };
    case 'qr': return { page: 'qr' };
    case 'data': return { page: 'data' };
    case 'settings': return { page: 'settings' };
    default: return { page: 'notfound' };
  }
}

export function href(r: Route): string {
  switch (r.page) {
    case 'dashboard': case 'notfound': return '#/';
    case 'forms': return `#/forms/${r.kind}`;
    case 'team': return `#/teams/${r.team}`;
    default: return `#/${r.page}`;
  }
}
```

```ts
import { matchLabel } from '@stingr/shared';

export const pct = (f: number | null | undefined): string => (f === null || f === undefined ? '—' : `${Math.round(f * 100)}%`);

export const num = (n: number | null | undefined, digits = 1): string =>
  n === null || n === undefined ? '—' : String(Number(n.toFixed(digits)));

export function ago(iso: string, now = Date.now()): string {
  const s = Math.round((now - Date.parse(iso)) / 1000);
  if (s < 45) return 'just now';
  if (s < 3600) return `${Math.round(s / 60)} min ago`;
  if (s < 86400) return `${Math.round(s / 3600)} h ago`;
  return new Date(iso).toLocaleDateString();
}

export function slotLabel(slot: string | undefined): string {
  if (!slot) return '?';
  return `${slot.startsWith('red') ? 'Red' : 'Blue'} ${slot.slice(-1)}`;
}

export function recordLabel(r: { kind: string; matchKey?: string; slot?: string; team: number; scout: string }): string {
  const who = r.scout ? ` (${r.scout})` : '';
  return r.kind === 'pit' ? `Pit · Team ${r.team}${who}` : `${matchLabel(r.matchKey ?? '')} · ${slotLabel(r.slot)} · Team ${r.team}${who}`;
}
```

```ts
export function sortBy<T>(rows: T[], get: (r: T) => number | string | null, dir: 'asc' | 'desc'): T[] {
  return [...rows].sort((a, b) => {
    const x = get(a);
    const y = get(b);
    if (x === null && y === null) return 0;
    if (x === null) return 1; // empty values last, whichever way we sort
    if (y === null) return -1;
    const c = typeof x === 'number' && typeof y === 'number' ? x - y : String(x).localeCompare(String(y));
    return dir === 'asc' ? c : -c;
  });
}
```

```svelte
<script lang="ts">
  import { normalizeMatchKey, type ScheduleMatch } from '@stingr/shared';
  import { onMount } from 'svelte';
  import type { Api } from '../lib/api';
  import ErrorNote from './ErrorNote.svelte';

  let { api }: { api: Api } = $props();

  type Row = { matchKey: string; teams: string[] };
  const COLS = ['Red 1', 'Red 2', 'Red 3', 'Blue 1', 'Blue 2', 'Blue 3'];
  let rows = $state<Row[]>([]);
  let tbaKeySet = $state(false);
  let csv = $state('');
  let csvErrors = $state<string[]>([]);
  let message = $state<string | null>(null);
  let error = $state<unknown>(null);
  let busy = $state(false);

  const toRows = (m: ScheduleMatch[]): Row[] =>
    m.map(x => ({ matchKey: x.matchKey, teams: [...x.red, ...x.blue].map(t => (t ? String(t) : '')) }));

  async function load() {
    const [sched, s] = await Promise.all([api.schedule(), api.settings()]);
    rows = toRows(sched);
    tbaKeySet = s.tbaKeySet;
  }

  onMount(() => { load().catch(e => { error = e; }); });

  async function act(fn: () => Promise<string>) {
    busy = true;
    error = null;
    message = null;
    csvErrors = [];
    try {
      message = await fn();
      await load();
    } catch (e) {
      error = e;
    } finally {
      busy = false;
    }
  }

  const fromTba = () => act(async () => {
    const r = await api.fetchTba();
    return r.scheduleReplaced
      ? `Downloaded ${r.matches} matches and ${r.teams} teams from The Blue Alliance.`
      : `The Blue Alliance has no matches for this event yet. The team list (${r.teams} teams) was updated and your schedule was kept.`;
  });

  const importCsv = () => act(async () => {
    const r = await api.importScheduleCsv(csv);
    if ('errors' in r) {
      csvErrors = r.errors;
      throw new Error('The schedule was not imported. Fix the lines below and try again.');
    }
    csv = '';
    return `Imported ${r.matches} match${r.matches === 1 ? '' : 'es'}.`;
  });

  const saveRows = () => act(async () => {
    const matches: ScheduleMatch[] = rows.map(r => {
      const t = r.teams.map(x => Number(x.trim().replace(/^frc/i, '')) || 0);
      return { matchKey: normalizeMatchKey(r.matchKey) ?? r.matchKey.trim(), red: [t[0], t[1], t[2]], blue: [t[3], t[4], t[5]] };
    });
    const saved = await api.saveSchedule(matches);
    return `Saved ${saved.length} matches.`;
  });

  async function readFile(e: Event & { currentTarget: HTMLInputElement }) {
    const file = e.currentTarget.files?.[0];
    if (file) csv = await file.text();
  }

  function addRow() {
    const last = rows.at(-1);
    const key = last ? normalizeMatchKey(last.matchKey) : null;
    const n = key?.startsWith('qm') ? Number(key.slice(2)) + 1 : rows.length + 1;
    rows = [...rows, { matchKey: `qm${n}`, teams: ['', '', '', '', '', ''] }];
  }
</script>

  {/if}

  <h3>Import a CSV file</h3>
  <p class="hint">Columns: match, red1, red2, red3, blue1, blue2, blue3 (a header row is optional). Match is a number for qualifications, or a key like sf2m1.</p>

  <button type="button" disabled={busy || !csv.trim()} onclick={importCsv}>Import CSV</button>

  {/if}

  </div>
```

```ts
import {
  allQuestions, type ChoiceOption, type ChoiceQuestion, type FormDef, type FormKind, type MultiQuestion,
  type Question, type QuestionType, type Section,
} from '@stingr/shared';

export const QUESTION_TYPES: { type: QuestionType; label: string }[] = [
  { type: 'counter', label: 'Counter (+/−)' },
  { type: 'toggle', label: 'Yes / No' },
  { type: 'choice', label: 'Single choice' },
  { type: 'multi', label: 'Multi-select' },
  { type: 'number', label: 'Number' },
  { type: 'text', label: 'Text' },
  { type: 'rating', label: 'Rating' },
  { type: 'timer', label: 'Timer' },
  { type: 'fieldmap', label: 'Field map' },
];

export const typeLabel = (t: QuestionType): string => QUESTION_TYPES.find(x => x.type === t)?.label ?? t;

export interface Selection { si: number; qi: number | null }

export function slugify(label: string): string {
  const s = label.toLowerCase().replace(/[^a-z0-9]+/g, '_').replace(/^_+|_+$/g, '');
  if (!s) return 'question';
  return /^[a-z]/.test(s) ? s : `q_${s}`;
}

export function uniqueKey(base: string, taken: Iterable<string>): string {
  const used = new Set(taken);
  if (!used.has(base)) return base;
  for (let i = 2; ; i++) if (!used.has(`${base}_${i}`)) return `${base}_${i}`;
}

export const questionKeys = (f: FormDef): string[] => allQuestions(f).map(q => q.key);

export function emptyForm(kind: FormKind): FormDef {
  const titles = kind === 'match' ? ['Auto', 'Teleop', 'Endgame'] : ['Robot'];
  return { kind, version: 0, assets: {}, sections: titles.map(t => ({ id: slugify(t), title: t, questions: [] })) };
}

const starterOptions = (): ChoiceOption[] => [{ value: 'option_1', label: 'Option 1' }, { value: 'option_2', label: 'Option 2' }];

export function newQuestion(type: QuestionType, label: string, taken: Iterable<string>): Question {
  const base = { key: uniqueKey(slugify(label), taken), label, required: false };
  switch (type) {
    case 'counter': return { ...base, type, min: 0, step: 1, default: 0 };
    case 'toggle': return { ...base, type, default: false };
    case 'choice': return { ...base, type, display: 'buttons', options: starterOptions() };
    case 'multi': return { ...base, type, options: starterOptions() };
    case 'number': return { ...base, type, integer: true };
    case 'text': return { ...base, type, multiline: false };
    case 'rating': return { ...base, type, max: 5 };
    case 'timer': return { ...base, type };
    case 'fieldmap': return { ...base, type, assetId: '', maxPoints: 1, redSide: 'left' };
  }
}

export function changeType(q: Question, type: QuestionType): Question {
  const fresh = newQuestion(type, q.label, []);
  return { ...fresh, key: q.key, required: q.required, ...(q.help ? { help: q.help } : {}) } as Question;
}

function swap<T>(list: T[], i: number, j: number): T[] {
  if (j < 0 || j >= list.length) return list;
  const copy = [...list];
  [copy[i], copy[j]] = [copy[j], copy[i]];
  return copy;
}

const withSection = (f: FormDef, si: number, fn: (s: Section) => Section): FormDef =>
  ({ ...f, sections: f.sections.map((s, i) => (i === si ? fn(s) : s)) });

export function addSection(f: FormDef, title = 'New section'): FormDef {
  const id = uniqueKey(slugify(title), f.sections.map(s => s.id));
  return { ...f, sections: [...f.sections, { id, title, questions: [] }] };
}

export const renameSection = (f: FormDef, si: number, title: string): FormDef => withSection(f, si, s => ({ ...s, title }));
export const removeSection = (f: FormDef, si: number): FormDef => ({ ...f, sections: f.sections.filter((_, i) => i !== si) });
export const moveSection = (f: FormDef, si: number, delta: -1 | 1): FormDef => {
  const sections = swap(f.sections, si, si + delta);
  return sections === f.sections ? f : { ...f, sections };
};

export function addQuestion(f: FormDef, si: number, type: QuestionType, label = 'New question'): FormDef {
  const q = newQuestion(type, label, questionKeys(f));
  return withSection(f, si, s => ({ ...s, questions: [...s.questions, q] }));
}

export const replaceQuestion = (f: FormDef, si: number, qi: number, q: Question): FormDef =>
  withSection(f, si, s => ({ ...s, questions: s.questions.map((x, i) => (i === qi ? q : x)) }));

export const removeQuestion = (f: FormDef, si: number, qi: number): FormDef =>
  withSection(f, si, s => ({ ...s, questions: s.questions.filter((_, i) => i !== qi) }));

/** Move a question up or down; at the end of a section it moves into the neighbouring section. */
export function moveQuestion(f: FormDef, si: number, qi: number, delta: -1 | 1): { form: FormDef; si: number; qi: number } {
  const section = f.sections[si];
  const target = qi + delta;
  if (target >= 0 && target < section.questions.length) {
    return { form: withSection(f, si, s => ({ ...s, questions: swap(s.questions, qi, target) })), si, qi: target };
  }
  const ti = si + delta;
  if (ti < 0 || ti >= f.sections.length) return { form: f, si, qi };
  const q = section.questions[qi];
  const without = removeQuestion(f, si, qi);
  const into = withSection(without, ti, s => ({ ...s, questions: delta < 0 ? [...s.questions, q] : [q, ...s.questions] }));
  return { form: into, si: ti, qi: delta < 0 ? into.sections[ti].questions.length - 1 : 0 };
}

const followsLabel = (key: string, label: string) => new RegExp(`^${slugify(label)}(_\\d+)?$`).test(key);

/** Rename a question. Its key follows the label only while unpublished and still derived from the old label. */
export function renameQuestion(f: FormDef, q: Question, label: string, locked: boolean): Question {
  if (locked || !followsLabel(q.key, q.label)) return { ...q, label };
  const taken = questionKeys(f).filter(k => k !== q.key);
  return { ...q, label, key: uniqueKey(slugify(label), taken) };
}

type WithOptions = ChoiceQuestion | MultiQuestion;

export function addOption<Q extends WithOptions>(q: Q, label = `Option ${q.options.length + 1}`): Q {
  const value = uniqueKey(slugify(label), q.options.map(o => o.value));
  return { ...q, options: [...q.options, { value, label }] } as Q;
}

export function renameOption<Q extends WithOptions>(q: Q, i: number, label: string, locked: boolean): Q {
  const o = q.options[i];
  const value = !locked && followsLabel(o.value, o.label)
    ? uniqueKey(slugify(label), q.options.filter((_, k) => k !== i).map(x => x.value))
    : o.value;
  return { ...q, options: q.options.map((x, k) => (k === i ? { ...x, label, value } : x)) } as Q;
}

export function setOptionValue<Q extends WithOptions>(q: Q, i: number, value: string): Q {
  return { ...q, options: q.options.map((x, k) => (k === i ? { ...x, value } : x)) } as Q;
}

export function setOptionPoints(q: ChoiceQuestion, i: number, points: number | undefined): ChoiceQuestion {
  return {
    ...q,
    options: q.options.map((x, k) => {
      if (k !== i) return x;
      const { points: _old, ...rest } = x;
      return points === undefined ? rest : { ...rest, points };
    }),
  };
}

export const removeOption = <Q extends WithOptions>(q: Q, i: number): Q => ({ ...q, options: q.options.filter((_, k) => k !== i) }) as Q;
export const moveOption = <Q extends WithOptions>(q: Q, i: number, delta: -1 | 1): Q => ({ ...q, options: swap(q.options, i, i + delta) }) as Q;

export function setFieldImage(f: FormDef, si: number, qi: number, dataUrl: string): FormDef {
  const q = f.sections[si].questions[qi];
  if (q.type !== 'fieldmap') return f;
  const assetId = q.assetId || uniqueKey(`field_${q.key}`, Object.keys(f.assets));
  return { ...replaceQuestion(f, si, qi, { ...q, assetId }), assets: { ...f.assets, [assetId]: dataUrl } };
}

export function pruneAssets(f: FormDef): FormDef {
  const used = new Set(allQuestions(f).flatMap(q => (q.type === 'fieldmap' && q.assetId ? [q.assetId] : [])));
  return { ...f, assets: Object.fromEntries(Object.entries(f.assets).filter(([id]) => used.has(id))) };
}
```

```svelte
<script lang="ts">
  import { allQuestions, type FormDef, type FormKind } from '@stingr/shared';
  import { onDestroy, onMount } from 'svelte';
  import ConfirmDialog from '../../../../app/src/components/ConfirmDialog.svelte';
  import ErrorNote from '../components/ErrorNote.svelte';
  import Outline from '../components/Outline.svelte';
  import Preview from '../components/Preview.svelte';
  import QuestionProps from '../components/QuestionProps.svelte';
  import type { Api, FormValidation } from '../lib/api';
  import { emptyForm, pruneAssets, type Selection } from '../lib/formEdit';

  let { api, kind }: { api: Api; kind: FormKind } = $props();

  let form = $state<FormDef | null>(null);
  let published = $state<FormDef[]>([]);
  let isDraft = $state(false);
  let validation = $state<FormValidation>({ errors: [], warnings: [] });
  let status = $state<'saved' | 'saving' | 'unsaved' | 'error'>('saved');
  let selected = $state<Selection>({ si: 0, qi: null });
  let error = $state<unknown>(null);
  let message = $state<string | null>(null);
  let confirmDiscard = $state(false);
  let showPreview = $state(true);
  let timer: ReturnType<typeof setTimeout> | null = null;

  let mine = $derived(published.filter(f => f.kind === kind));
  let latest = $derived(mine.at(-1) ?? null);
  let lockedKeys = $derived(new Set(mine.flatMap(f => allQuestions(f).map(q => q.key))));
  let lockedOptions = $derived.by(() => {
    const m = new Map<string, Set<string>>();
    for (const f of mine) {
      for (const q of allQuestions(f)) {
        if (q.type !== 'choice' && q.type !== 'multi') continue;
        const set = m.get(q.key) ?? new Set<string>();
        for (const o of q.options) set.add(o.value);
        m.set(q.key, set);
      }
    }
    return m;
  });
  let statusText = $derived(
    status === 'saving' ? 'Saving…'
      : status === 'unsaved' ? 'Unsaved changes…'
        : status === 'error' ? "Couldn't save the draft (see the message above)."
          : isDraft ? `Draft saved · not published yet${latest ? ` (published: version ${latest.version})` : ''}`
            : latest ? `Published version ${latest.version} · no unpublished changes` : 'Nothing published yet',
  );

  onMount(async () => {
    try {
      const [d, forms] = await Promise.all([api.draft(kind), api.forms()]);
      published = forms;
      isDraft = d.isDraft;
      form = d.draft ?? emptyForm(kind);
    } catch (e) {
      error = e;
    }
  });

  // Leaving the page must not lose an edit that is still waiting for the autosave delay.
  onDestroy(() => {
    if (timer) {
      clearTimeout(timer);
      void save();
    }
  });

  function edit(next: FormDef) {
    form = next;
    status = 'unsaved';
    message = null;
    if (timer) clearTimeout(timer);
    timer = setTimeout(() => void save(), 600);
  }

  async function save() {
    timer = null;
    if (!form) return;
    status = 'saving';
    try {
      validation = await api.saveDraft(kind, pruneAssets($state.snapshot(form) as FormDef));
      isDraft = true;
      status = 'saved';
    } catch (e) {
      status = 'error';
      error = e;
    }
  }

  async function publish() {
    if (timer) {
      clearTimeout(timer);
      await save();
    }
    error = null;
    try {
      const res = await api.publish(kind);
      if (res.ok) {
        published = [...published, res.form];
        form = res.form;
        isDraft = false;
        validation = { errors: [], warnings: res.warnings };
        message = `Published version ${res.form.version}. Tablets get it on their next sync.`;
      } else {
        validation = { errors: res.errors, warnings: res.warnings };
      }
    } catch (e) {
      error = e;
    }
  }

  async function discard() {
    confirmDiscard = false;
    if (timer) {
      clearTimeout(timer);
      timer = null;
    }
    try {
      const d = await api.discardDraft(kind);
      form = d.draft ?? emptyForm(kind);
      isDraft = false;
      status = 'saved';
      validation = { errors: [], warnings: [] };
      selected = { si: 0, qi: null };
      message = 'Changes discarded.';
    } catch (e) {
      error = e;
    }
  }

  function exportJson() {
    if (!form) return;
    const blob = new Blob([JSON.stringify(pruneAssets($state.snapshot(form) as FormDef), null, 2)], { type: 'application/json' });
    const a = document.createElement('a');
    a.href = URL.createObjectURL(blob);
    a.download = `${kind}-form.json`;
    a.click();
    URL.revokeObjectURL(a.href);
  }

  async function importJson(e: Event & { currentTarget: HTMLInputElement }) {
    const input = e.currentTarget;
    const file = input.files?.[0];
    input.value = '';
    if (!file) return;
    try {
      const parsed = JSON.parse(await file.text()) as FormDef;
      if (!Array.isArray(parsed.sections)) throw new Error('That file is not a Stingr Scout form.');
      edit({ ...parsed, kind, version: 0, assets: parsed.assets ?? {} });
      selected = { si: 0, qi: null };
    } catch (err) {
      error = err instanceof SyntaxError ? new Error('That file is not valid JSON.') : err;
    }
  }
</script>

<h1>{kind === 'match' ? 'Match form' : 'Pit form'}</h1>
<ErrorNote {error} />

{#if form}
  <div class="row">
    <span class="grow" role="status">{statusText}</span>
    <button type="button" onclick={() => (showPreview = !showPreview)}>{showPreview ? 'Hide preview' : 'Show preview'}</button>
    <button type="button" onclick={exportJson}>Export JSON</button>
    <label class="filebtn">Import JSON<input type="file" accept="application/json,.json" hidden aria-label="Import JSON file" onchange={importJson} /></label>
    <button type="button" disabled={!isDraft && status === 'saved'} onclick={() => (confirmDiscard = true)}>Discard changes</button>
    <button type="button" class="primary" onclick={publish}>Publish</button>
  </div>

  {#if message}<p class="banner ok">{message}</p>{/if}
  {#if validation.errors.length}
    <div class="banner warn">
      <strong>Fix these before publishing:</strong>
      <ul class="errors">{#each validation.errors as e, i (i)}<li>{e}</li>{/each}</ul>
    </div>
  {/if}
  {#if validation.warnings.length}
    <div class="banner warn"><ul>{#each validation.warnings as w, i (i)}<li>{w}</li>{/each}</ul></div>
  {/if}

  <div class="editor">
    <Outline {form} {selected} onselect={s => (selected = s)} onchange={edit} />
    <div>
      {#if selected.qi !== null && form.sections[selected.si]?.questions[selected.qi]}
        <QuestionProps {form} si={selected.si} qi={selected.qi} {lockedKeys} {lockedOptions} onchange={edit} />
      {:else}
        <p class="card muted">Select a question to change it, or add one.</p>
      {/if}
      {#if showPreview}<Preview {form} />{/if}
    </div>
  </div>
{/if}

{#if confirmDiscard}
  <ConfirmDialog
    title="Discard unpublished changes?"
    confirmLabel="Discard"
    cancelLabel="Keep editing"
    onconfirm={discard}
    oncancel={() => (confirmDiscard = false)}
  >
    <p>The form goes back to {latest ? `published version ${latest.version}` : 'empty'}.</p>
  </ConfirmDialog>
{/if}
```

```svelte
  import { onMount } from 'svelte';
```

```svelte
  type Col = { id: string; label: string; get: (s: TeamSummary) => number | string | null; show: (s: TeamSummary) => string };

  let data = $state<{ form: FormDef | null; summaries: TeamSummary[] } | null>(null);
  let error = $state<unknown>(null);
  let sortId = $state('est');
  let dir = $state<'asc' | 'desc'>('desc');
  const PIT = { none: '—', done: '✓', noshow: 'Not present' } as const;

  onMount(async () => {
    try {
      data = await api.summaries();
    } catch (e) {
      error = e;
    }
  });

  function topOption(s: TeamSummary, q: ChoiceQuestion): { label: string; share: number } | null {
    const st = s.stats[q.key];
    if (st?.kind !== 'distribution' || !st.n) return null;
    const best = Object.entries(st.counts).sort((a, b) => b[1] - a[1])[0];
    if (!best) return null;
    return { label: q.options.find(o => o.value === best[0])?.label ?? best[0], share: best[1] / st.n };
  }

  let cols = $derived.by((): Col[] => {
    const list: Col[] = [
      { id: 'team', label: 'Team', get: s => s.team, show: s => String(s.team) },
      { id: 'matches', label: 'Matches', get: s => s.matchRecords, show: s => String(s.matchRecords) },
      { id: 'noshow', label: 'No-shows', get: s => s.noShowPct, show: s => pct(s.noShowPct) },
      { id: 'est', label: 'Est. points', get: s => s.estPoints, show: s => num(s.estPoints) },
    ];
    const form = data?.form;
    if (form) {
      for (const sec of form.sections) {
        const scores = sec.questions.some(q =>
          ((q.type === 'counter' || q.type === 'toggle') && q.points !== undefined) || (q.type === 'choice' && q.options.some(o => o.points !== undefined)));
        if (scores) list.push({ id: `sec_${sec.id}`, label: `${sec.title} pts`, get: s => s.estPointsBySection[sec.id] ?? null, show: s => num(s.estPointsBySection[sec.id]) });
      }
      for (const q of allQuestions(form)) {
        const kind = summaryKind(q);
        if (kind === 'avg') {
          list.push({
            id: q.key, label: q.label,
            get: s => { const st = s.stats[q.key]; return st?.kind === 'avg' ? st.avg : null; },
            show: s => { const st = s.stats[q.key]; return st?.kind === 'avg' ? num(st.avg) : '—'; },
          });
        } else if (kind === 'pct') {
          list.push({
            id: q.key, label: q.label,
            get: s => { const st = s.stats[q.key]; return st?.kind === 'pct' ? st.pct : null; },
            show: s => { const st = s.stats[q.key]; return st?.kind === 'pct' ? pct(st.pct) : '—'; },
          });
        } else if (kind === 'distribution' && q.type === 'choice') {
          list.push({
            id: q.key, label: q.label,
            get: s => topOption(s, q)?.share ?? null,
            show: s => { const t = topOption(s, q); return t ? `${t.label} ${pct(t.share)}` : '—'; },
          });
```

```ts
import jsQR from 'jsqr';

/** True when this text was seen less than windowMs ago. Every sighting refreshes the time. */
export function createRepeatFilter(windowMs = 3000): (text: string, now: number) => boolean {
  const lastSeen = new Map<string, number>();
  return (text, now) => {
    const last = lastSeen.get(text);
    lastSeen.set(text, now);
    return last !== undefined && now - last < windowMs;
  };
}

/** Open the camera into `video` and report every QR code seen. Returns a function that stops it. */
export async function startScanner(video: HTMLVideoElement, onText: (text: string) => void): Promise<() => void> {
  const stream = await navigator.mediaDevices.getUserMedia({ video: { facingMode: 'environment', width: { ideal: 1280 } }, audio: false });
  video.srcObject = stream;
  await video.play();
  const canvas = document.createElement('canvas');
  const ctx = canvas.getContext('2d', { willReadFrequently: true });
  let running = true;
  let frame = 0;
  const loop = () => {
    if (!running) return;
    if (ctx && video.readyState >= 2 && frame++ % 3 === 0) {
      canvas.width = video.videoWidth;
      canvas.height = video.videoHeight;
      ctx.drawImage(video, 0, 0);
      const img = ctx.getImageData(0, 0, canvas.width, canvas.height);
      const code = jsQR(img.data, img.width, img.height, { inversionAttempts: 'dontInvert' });
      if (code?.data) onText(code.data);
    }
    requestAnimationFrame(loop);
  };
  requestAnimationFrame(loop);
  return () => {
    running = false;
    for (const t of stream.getTracks()) t.stop();
    video.srcObject = null;
  };
}
```

```svelte
  import type { Api, QrResult } from '../lib/api';

  let log = $state<Entry[]>([]);
  let pasted = $state('');
  let video = $state<HTMLVideoElement>();
  let running = $state(false);
  let cameraError = $state<string | null>(null);
  let stopCamera: (() => void) | null = null;
  const isRepeat = createRepeatFilter();
  let nextId = 0;

  function describe(r: QrResult): Omit<Entry, 'id'> {
    switch (r.status) {
      case 'stored': return { kind: 'ok', text: `Stored: ${recordLabel(r.record)}` };
      case 'duplicate': return { kind: 'info', text: `Already had: ${recordLabel(r.record)}` };
      case 'partial': return { kind: 'info', text: `Got part ${r.have} of ${r.total}. Keep scanning the other codes.` };
      case 'invalid': return { kind: 'bad', text: `Not stored: ${r.reason}` };
    }
  }

  async function submit(text: string) {
    try {
      const entry = describe(await api.qr(text));
      log = [{ ...entry, id: ++nextId }, ...log].slice(0, 50);
    } catch (e) {
      log = [{ id: ++nextId, kind: 'bad' as const, text: (e as Error).message }, ...log].slice(0, 50);
    }
  }

  async function submitPasted() {
    // Keep trailing spaces: base45 data can end with one.
    const text = pasted.replace(/^\s+/, '').replace(/[\r\n]+$/, '');
    pasted = '';
    if (text) await submit(text);
  }

  async function start() {
    cameraError = null;
    if (!navigator.mediaDevices?.getUserMedia || !video) {
      cameraError = "This browser can't use a camera here. Paste the QR text instead.";
      return;
    }
    try {
      stopCamera = await startScanner(video, text => { if (!isRepeat(text, Date.now())) void submit(text); });
      running = true;
    } catch (e) {
      cameraError = `Couldn't start the camera: ${(e as Error).message}`;
    }
  }

  function stop() {
    stopCamera?.();
    stopCamera = null;
    running = false;
  }

  onDestroy(stop);
```

```svelte
  onMount(() => {
    const onHash = () => { route = parseRoute(location.hash); };
    window.addEventListener('hashchange', onHash);
    return () => window.removeEventListener('hashchange', onHash);
  });

  const NAV: { label: string; route: Route }[] = [
    { label: 'Dashboard', route: { page: 'dashboard' } },
    { label: 'Event setup', route: { page: 'event' } },

    if (r.page === 'forms') return route.page === 'forms' && route.kind === r.kind;
    if (r.page === 'teams') return route.page === 'teams' || route.page === 'team';
    return r.page === route.page;
  }
</script>
```
